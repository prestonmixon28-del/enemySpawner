The factory puts the object creation in one place.This makes the main program less dependent on specific enemy classes and makes it easier to add new enemy types later.

The factory method patterns lets different spawners create different types of enemies. This makes the program easier to organize and add new enemy types.

The abstract factory pattern creates related objects together. The warrior factory creates a sword and plate armor, while the mage factory creates a staff and robe.
